# bicel
It's an app where people can list items they want to sell and also checkout the products listed by others to buy. It's inspired by OLX. I made it for my learning.

## Getting API Access for AI Models Through Education Benefits

This section provides guidance for developers and students who want to integrate AI capabilities into their apps (like this one) using free credits from education programs.

### Microsoft Azure for Students
1. Sign up at [Azure for Students](https://azure.microsoft.com/en-us/free/students/)
2. Verify your academic email
3. Access Azure OpenAI Service through the [Azure Portal](https://portal.azure.com/)
4. Create an Azure OpenAI resource and get your API key from the resource's "Keys and Endpoint" section

### Google Cloud for Education
1. Apply at [Google Cloud for Education](https://cloud.google.com/edu/)
2. Once approved, access the [Google Cloud Console](https://console.cloud.google.com/)
3. Enable the AI/ML APIs you need (Vertex AI, etc.)
4. Create API credentials in the [Credentials section](https://console.cloud.google.com/apis/credentials)

### OpenAI (API Credits)
1. If you received OpenAI credits through an education program, sign in at [platform.openai.com](https://platform.openai.com/)
2. Go to [API Keys](https://platform.openai.com/api-keys) to create a new key
3. Your credits will be visible in the [Usage section](https://platform.openai.com/usage)

### GitHub Education Benefits
1. Verify your student status at [GitHub Education](https://education.github.com/)
2. Access free tools and services included in the Student Developer Pack
3. Some partner services in the pack offer AI/ML API credits

### General Tips
- Keep your API keys secure and never commit them to public repositories
- Use environment variables or secure vault services to store API keys
- Check the documentation of each provider for usage limits and quotas
